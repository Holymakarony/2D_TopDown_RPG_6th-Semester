# 2D TopDown RPG – Modulare C# Anwendungsarchitektur

Dieses Projekt entstand als fortgeschrittenes Softwareprojekt im 6. Semester meiner Ausbildung an der htk academy. Der Fokus lag auf dem Entwurf einer skalierbaren, wartbaren und performanten Systemarchitektur unter strikter Einhaltung moderner Software-Design-Prinzipien.

## 🛠️ Technische Highlights & Software-Konzepte
* **Objektorientierte Architektur (OOP):** Konsequente Anwendung von Kapselung, Vererbung und Polymorphie zur sauberen Trennung von Datenhaltungs- und Steuerungssystemen.
* **Design Patterns:** Integration bewährter Entwurfsmuster (z. B. State Pattern für komplexe Zustandsmaschinen oder Observer Pattern zur Event-basierten Kommunikation).
* **Datenmanagement:** Effiziente Strukturierung, Serialisierung und Verwaltung dynamischer Objekt- und Systemdaten.
* **Clean Code & Refactoring:** Fokus auf selbsterklärende Namenskonventionen, Vermeidung von Redundanzen (DRY-Prinzip) und optimierte Speichereffizienz zur Reduzierung der Garbage Collection.

## 🚀 Technologien & Tools
* **Programmiersprache:** C# (.NET-Infrastruktur)
* **Plattform/Engine:** Unity 2D
* **Versionskontrolle:** Git
* **Entwicklungsumgebung:** Visual Studio
